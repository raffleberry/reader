# AGENTS.md

EPUB Reader + read-aloud, as a browser extension (WXT, MV3) plus a Go speech helper. Books live only in the open tab; the helper only turns text into audio. Git repo, origin `github.com:raffleberry/reader` (branch `main`).

## Commands (`just` is truth; don't invent)

- `setup` (go mod download + bun install) · `server` (tray) · `host-install [ID]` (register the helper for dev) · `ext` / `ext-firefox` (wxt dev, opens a browser with the extension)
- `build` → extension/.output/chrome-mv3 · `build-firefox` → .output/firefox-mv3 · `zip` (both store archives) · `check` (go vet + go test + vitest + vue-tsc + build) · `e2e` (playwright vs the built extension + the real binary; first time: `bun x playwright install chromium`) · `package` (go build → dist/epub-reader) · `package-all` (linux + windows)
- JS CLI runs under bun (`bun x wxt …`); no node/npm in this environment.

## Helper (`server/`, Go module `github.com/raffleberry/reader/server`)

- One binary, three jobs: tray (default with a terminal; auto-installs the manifest on first run via `gogpu/systray`), native host (`--native-host` or stdin-is-a-pipe: length-prefixed stdio loop until EOF, then exit), `--install`/`--uninstall`. `--extension-id` (repeatable) + `EPUB_READER_EXTENSION_IDS` authorise Chrome unpacked ids; Firefox's `reader@raffleberry.github.io` is built in. Host name `com.raffleberry.epubreader`, app `epub-reader`.
- Methods: `ping` (`{ok, version}`), `getSettings`/`putSettings`, `cacheStats`/`clearCache`, `speak {text, voice?}` (base64 MP3 + words), `ttsWords`, `prefetch {texts}` (first 20, junk skipped). Speech fail → `ok:false`.
- Settings: validated JSON (`cache_mb` 10-2000, `readahead` 0-10, voice str) in the system config dir; `saveSettings` re-trims the cache. `Lru` = bounded on-disk MP3+timings cache keyed `sha1(voice+text)`; `cacheStore()` rebuilds when the base changes so tests pin temp dirs via `EPUB_READER_CACHE_DIR` / `EPUB_READER_CONFIG_FILE`.
- Speech via `github.com/raffleberry/edge-tts-go` (`NewCommunicate` + `Stream`, `WordBoundary`; ticks/10000 = ms).
- Dirs: `~/.cache/epub-reader/tts`, `~/.config/epub-reader/settings.json` (Linux; OS dirs elsewhere).

## Extension (`extension/`, WXT + bun, TS `<script setup>`, Bootstrap; custom CSS in src/assets/app.css)

- `wxt.config.ts`: `srcDir:'src'` (so `entrypoints/` sits next to `views/`), `modules:['@wxt-dev/module-vue','@wxt-dev/auto-icons']`, **`imports:false`** (explicit imports only), `autoIcons.baseIconPath:'assets/icon.svg'`. Manifest is generated: `storage` + `nativeMessaging` only (no `host_permissions`: speech is not HTTP), `action` with no popup, `options_ui`, gecko id + `data_collection_permissions` for Firefox. Firefox needs `--mv3`.
- `entrypoints/`: `background.ts` (toolbar → open/focus reader.html; tab id in **session** storage + `tabs.onRemoved`; no `tabs` permission), `reader/` (unlisted page, mounts App), `options/` (mounts views/Options). Both hydrate prefs before mount.
- `ext/`: `settings.ts` (`storage.defineItem` per pref — never localStorage; no server address any more), `serve.ts` (one persistent `connectNative(HOST)` port, ids routed to waiters, `probe()`, `downMessage()`, `ServerDown`, `onServerDown`/`reportDown`; prefers page `chrome`/`browser` globals so tests stub the `chrome` global, falls back to WXT `browser`), `shelf.ts` (≤8 "where I was" notes; fingerprint = `sha-256(size‖mtime‖first 256 KB)` so a rename/move still matches; evicts a book's bookmarks with it), `marks.ts` (bookmarks: ≤200/book, filed under the same fingerprint — a sentence index, a chapter label and ≤`TEXT_MAX` chars of the excerpt; `watchBook` keeps an open panel live).
- `store/`: `prefs` (hydrated reactive settings + helper state; `watchStorage()` keeps sidebar and options page in step; `markDown()` on a failed spawn; `watchServer()` 15 s ping while the tab is visible; `ensureServer()` gate before speaking), `reader` (`open(File)` in memory, `playFrom()`, debounced `scheduleSave` + `flushPlace`, `setPages`), `player` (lookahead queue, run/play tokens, rAF word sync, `busy` covers playing/loading/paused, `rerender(doc)` re-anchors a highlight after epub.js rewrites a chapter), `sidecar` (toc | marks | settings).
- `api/`: `voice.ts` + `settings.ts` — native `request()` calls; a missing helper → `reportDown()` + `ServerDown` (that message is the "download the helper" prompt); helper errors (bad text, TTS failure) surface as plain Errors.
- `tts/`: `locate.ts` (sentence→DOM back-map incl. whitespace-only nodes; words painted via live-DOM search; `placeSentences`/`sentenceIndexAtSelection` resolve by DOM position), `mark.ts` (the live highlight as *text*: `show`/`current`/`reapply`/`clear`, so it survives any document rewrite), `cfi.ts` (`spinePosOf`, `sameChapter` — used to decide whether a saved place is still the chapter you're in), `sound.ts` (the one module-scope `Audio` + rate + blob-URL swapping).
- Views: `OpenBook` (start screen: picker, whole-page drag & drop, the "recently read" list — notes + progress + bookmark count and one delete button, **never an open button**: the book isn't there to open), `Reader` (no settings route — settings live in the sidecar), `Options`. Components: `Sidecar`, `ReaderBar`, `ServerBadge`, `RecentCard`, `TocList`, `BookmarksPanel`, `SettingsPanel`.
- Prefs: theme, font, rate, readahead, autoscroll, voice. There is no scroll-direction setting: the book is one scrollable, so the wheel is the browser's.
- Reader: `EpubView` + custom chrome; depend only on `BookRendition` (`types.ts`), never the epubjs `Rendition` class. Gotchas: `openAs:'binary'`; `.reader-frame` must be `relative` + neutralize EpubView's absolute `.reader` inset; iframe keys owned by us (`enable-key=false`, `enable-wheel=false` — the wheel is the browser's now); location state (cfi/href/spine) comes from our own `relocated` listener; chrome is static in-flow edges; a ResizeObserver re-measures the rendition. **`hooks.content` fires on every re-render too**: `rendition.resize()` → `manager.resize()` → `views.clear()` + re-render, so hiding the sidebar destroys the chapter document — always call `rerender(doc)` there (after `applyPage(doc)`) to put the highlight back.
- **One continuous scroll**: `epubOptions = {flow:'scrolled-doc', manager:'continuous'}`. The continuous manager stacks whole chapters in the single `.epub-container` scroll and appends/prepends as you reach one; the wheel, the scrollbar and the arrows (a screenful via `rendition.next()`) are the only navigation. It decides to stack more from the container's scroll height and re-checks **only on scroll** — so `Reader.vue`'s `stackAhead()` calls `manager.fill()` on every `relocated`: the first section's height settles *after* epub.js's own `fill()` ran, and a section that fits the screen leaves nothing to scroll, so without it the book stays one chapter long. Each new section relocates, so it converges.
- Missing helper is a normal state, shown in three places: `ServerBadge` (reader bar), a dismissible banner over the book, and the player-error row; `player.start` probes first, and play/resume are **disabled** while it is down.
- Deps: `@floating-ui/dom`, `jsdom@26` for vitest (jsdom 30 breaks vitest 5's env setup), TS v5 (vue-tsc breaks on v7).

## Tests

`server/*_test.go` — settings, LRU, native framing + dispatch over pinned temp dirs; offline-safe, speech never touched.
`extension/test/` — vitest: `locate` (sentence/word paints), `mark` (the highlight survives a re-rendered document), `player` (`ensureSentenceDoc` with a fake rendition), `selection` (read-from-here DOM position), `settings` (voices, per-theme highlight CSS, per-theme link colours incl. contrast + `!important`, rate clamp/persist, helper state), `serve` (native routing, shared port, helper errors, `ServerDown`, `reportDown`), `shelf` (fingerprint, LRU cap, nothing book-shaped stored), `marks` (bookmarks per book, newest first, per-book cap, a dropped book takes its bookmarks, a bookmark holds only an index + a short excerpt). `test/blob.ts` shims `Blob.arrayBuffer()` (jsdom lacks it).
`extension/e2e/` — `extension.spec.ts` vs `.output/chrome-mv3` in a persistent context (manifest permissions, toolbar opens the reader, missing helper reported honestly + play disabled, hiding the sidebar re-renders the chapter and Reader re-hooks it, picked EPUB renders and leaves only a `shelf` entry, one continuous scroll + selection→bookmark→counted→deleted with the book) + `server.spec.ts` (builds the real Go binary, talks framed native JSON at it: ping, settings, validation, prefetch — skipped without Go). `e2e/chapter.ts` holds the frame helpers: several chapter documents are live at once, so a test must pick the frame it means (`proseFrame`, `frameWith`, `replacedFrame`) and a chapter's own coordinates say nothing about the viewport — add the iframe's offset.
