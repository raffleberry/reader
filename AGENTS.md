# AGENTS.md

EPUB Reader + read-aloud, as a browser extension (WXT, MV3) plus a Go speech helper. Books live only in the open tab; the helper only turns text into audio. Git repo, origin `github.com:raffleberry/reader` (branch `main`).

## Commands (`just` is truth; don't invent)

- `setup` (go mod download + bun install) · `tts` (run the helper: installs with a report, then exits) · `host-install [ID]` (register the helper for dev) · `ext` / `ext-firefox` (wxt dev, opens a browser with the extension)
- `build` → extension/.output/chrome-mv3 · `build-firefox` → .output/firefox-mv3 · `zip` (both store archives) · `check` (go vet + go test + vitest + vue-tsc + build) · `e2e` (playwright vs the built extension + the real binary; first time: `bun x playwright install chromium`) · `package` (go build → dist/reader) · `package-all` (linux + windows)
- JS CLI runs under bun (`bun x wxt …`); no node/npm in this environment.

## Helper (`tts/`, Go module `github.com/raffleberry/reader/tts`)

- One binary, two jobs: user launch (a terminal install with a per-manifest report, then exit; nothing stays running), native host (`--native-host` or stdin-is-a-pipe: length-prefixed stdio loop until EOF, then exit), plus `--install`/`--uninstall`. `--extension-id` (repeatable) + `READER_EXTENSION_IDS` authorise Chrome unpacked ids; Firefox's `reader@io.github.raffleberry` is built in. Host name `io.github.raffleberry.reader`, app `reader`. No GUI, no tray: there is no `--tray` flag (it exits with a pointer to just run the binary).
- Methods: `ping` (`{ok, version}`), `getSettings`/`putSettings`, `cacheStats`/`clearCache`, `speak {text, voice?}` (base64 MP3 + words), `ttsWords`, `prefetch {texts}` (first 20, junk skipped). Speech fail → `ok:false`.
- Settings: validated JSON (`cache_mb` 10-2000, `readahead` 0-10, voice str) in the system config dir; `saveSettings` re-trims the cache. `Lru` = bounded on-disk MP3+timings cache keyed `sha1(voice+text)`; `cacheStore()` rebuilds when the base changes so tests pin temp dirs via `READER_CACHE_DIR` / `READER_CONFIG_FILE`.
- Speech via `github.com/raffleberry/edge-tts-go` (`NewCommunicate` + `Stream`, `WordBoundary`; ticks/10000 = ms).
- Dirs: `~/.cache/io.github.raffleberry/reader/tts`, `~/.config/io.github.raffleberry/reader/` (binary + `settings.json`) on Linux; OS dirs elsewhere.

## Extension (`extension/`, WXT + bun, TS `<script setup>`, Bootstrap; custom CSS in src/assets/app.css)

- `wxt.config.ts`: `srcDir:'src'` (so `entrypoints/` sits next to `views/`), `modules:['@wxt-dev/module-vue','@wxt-dev/auto-icons']`, **`imports:false`** (explicit imports only), `autoIcons.baseIconPath:'assets/icon.svg'`. Manifest is generated: `storage` + `nativeMessaging` only (no `host_permissions`: speech is not HTTP), `action` with no popup, `options_ui`, gecko id + `data_collection_permissions` for Firefox. Firefox needs `--mv3`.
- `entrypoints/`: `background.ts` (toolbar → open/focus reader.html; tab id in **session** storage + `tabs.onRemoved`; no `tabs` permission), `reader/` (unlisted page, mounts App), `options/` (mounts views/Options). Both hydrate prefs before mount.
- `ext/`: `settings.ts` (`storage.defineItem` per pref — never localStorage; no server address any more), `serve.ts` (one persistent `connectNative(HOST)` port, ids routed to waiters, `probe()`, `downMessage()`, `ServerDown`, `onServerDown`/`reportDown`; prefers page `chrome`/`browser` globals so tests stub the `chrome` global, falls back to WXT `browser`), `shelf.ts` (≤8 "where I was" notes; fingerprint = `sha-256(size‖mtime‖first 256 KB)` so a rename/move still matches; evicts a book's bookmarks with it), `marks.ts` (bookmarks: ≤200/book, filed under the same fingerprint — a sentence index, a chapter label and ≤`TEXT_MAX` chars of the excerpt; `watchBook` keeps an open panel live).
- `store/`: `prefs` (hydrated reactive settings + helper state; `watchStorage()` keeps sidebar and options page in step; `watchServer()` 15 s ping while the tab is visible; `ensureServer()` gate before speaking), `reader` (`open(File)` in memory via foliate, sentence inventory, `playFrom()`, debounced `scheduleSave` + `flushPlace`, `setPages`, `setSection`), `player` (lookahead queue, run/play tokens, rAF word sync, `busy` covers playing/loading/paused, `ensureSection` navigates to a sentence's section first), `sidecar` (toc | marks | settings).
- `api/`: `voice.ts` + `settings.ts` — native `request()` calls; a missing helper → `reportDown()` + `ServerDown` (that message is the "download the helper" prompt); helper errors (bad text, TTS failure) surface as plain Errors.
- `tts/`: `locate.ts` (range→span wrapping; words painted via live-DOM search), `mark.ts` (the live highlight: `showRange`/`current`/`clear`), `cfi.ts` (`sameChapter` — used to decide whether a saved place is still the section you're in), `sound.ts` (the one module-scope `Audio` + rate + blob-URL swapping).
- Views: `OpenBook` (start screen: picker, whole-page drag & drop, the "recently read" list — notes + progress + bookmark count and one delete button, **never an open button**: the book isn't there to open), `Reader` (no settings route — settings live in the sidecar), `Options`. Components: `Sidecar`, `ReaderBar`, `ServerBadge`, `RecentCard`, `TocList`, `BookmarksPanel`, `SettingsPanel`.
- Prefs: theme, font, rate, readahead, autoscroll. Voice lives in the helper, not here. There is no scroll-direction setting: sections scroll natively, so the wheel is the browser's.
- Reader: a foliate-js paginator (`flow="scrolled"`) + custom chrome. The vendored tree lives in `vendor/foliate-js` (see `VERSION.txt` there for the pinned commit; updates are manual, never a submodule); only the EPUB modules enter the bundle (`epub`, `epubcfi`, `paginator`, `text-walker` via our own segmentation — never `view.js`, which would drag the MOBI/PDF/comic parsers in). Depend only on the facades (`src/foliate/`: `openEPUB`, `mountView`), never the vendor modules directly — untyped JS (`src/vendor.d.ts`), full types on our side. Gotchas: foliate's zip needs `configure({useWebWorkers:false})` (extension pages have no worker URL; without it `open()` hangs with no error); book scripts are stripped in `openEPUB` via `transformTarget` (sections render same-origin: no `<script>`, no `on*`, no `javascript:` URLs); themes go through the paginator's `setStyles()` (the paginator force-sets layout props itself, colours are ours); location state (section CFI + fraction) comes from our own `relocate` listener; `.folio-host` must pin the paginator (`position:absolute; inset:0`, the host div stays mounted while "Opening" shows — a `v-if` swap of the host destroys the viewer mid-mount); mount with a run token (`detachView()` first, *then* mint — mint-then-detach destroys its own view); the paginator self-observes resizes, so there is no resize hookup.
- **One section at a time**: the paginator keeps exactly one section document loaded and unloads the rest; TOC/scrubber/bookmarks/narration navigate explicitly (`goTo({index, anchor})`, `prev/next` turn pages and cross sections on their own). Progress is chars-weighted (1000 chars ≈ one page) from the sentence inventory. There is no document destruction on resize, so highlights survive sidebar toggles — nothing re-hooks anything.
- Missing helper is a normal state, shown in three places: `ServerBadge` (reader bar), a dismissible banner over the book, and the player-error row; `player.start` probes first, and play/resume are **disabled** while it is down.
- Deps: `@floating-ui/dom`, `jsdom@26` for vitest (jsdom 30 breaks vitest 5's env setup), TS v5 (vue-tsc breaks on v7).

## Tests

`tts/*_test.go` — settings, LRU, native framing + dispatch over pinned temp dirs; offline-safe, speech never touched.
`extension/test/` — vitest: `sentences` (Intl.Segmenter splits, ranges resolve per position incl. repeats, selection points, section starts), `mark` (range wrapping, word pills, clear), `player` (`ensureSection` with a fake viewer), `speak` (speakable check), `settings` (voices, per-theme highlight CSS, per-theme link colours incl. contrast + `!important`, rate clamp/persist, helper state), `serve` (native routing, shared port, helper errors, `ServerDown`, `reportDown`), `shelf` (fingerprint, LRU cap, nothing book-shaped stored), `marks` (bookmarks per book, newest first, per-book cap, a dropped book takes its bookmarks, a bookmark holds only an index + a short excerpt). `test/blob.ts` shims `Blob.arrayBuffer()` (jsdom lacks it).
`extension/e2e/` — `extension.spec.ts` vs `.output/chrome-mv3` in a persistent context (manifest permissions, toolbar opens the reader, missing helper reported honestly + play disabled, hiding the sidebar keeps the highlight, picked EPUB renders and leaves only a `shelf` entry, section scroll + TOC jump + selection→bookmark→counted→deleted with the book) + `tts.spec.ts` (builds the real Go binary, talks framed native JSON at it: ping, settings, validation, prefetch — skipped without Go). `e2e/chapter.ts` holds the frame helpers: one section document is live at a time, so a test picks the frame with prose (`proseFrame`, `frameWith`); selectors stop at the paginator's closed shadow root, so tests go through frame objects, and a chapter's own coordinates say nothing about the viewport — add the iframe's offset.

## Guidance

Flat modules, short Go-style names, full types on the TS boundary.
