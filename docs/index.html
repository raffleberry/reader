Read your EPUB books aloud, in your browser

EPUB Reader opens an .epub from your computer, lets you read it comfortably, and reads it to you out loud with word-by-word highlighting. Your books never leave your machine — and are forgotten the moment you close the tab.

Features

📖

Read section by section

Each chapter reads as its own clean scroll — move between chapters from the contents, the progress bar, or a bookmark.

🔊

Read-aloud with highlighting

A natural voice reads each chapter; the sentence lights up, then each word as it is spoken. 47 English voices, half to double speed.

🔖

Pick up where you stopped

Reopen the same file and you're back on the page — pressing play continues from the sentence the voice was on.

🔖

Bookmarks

Select a passage and mark it. Newest first, click to jump back — they survive renames and moves.

☾

Comfortable reading

Four themes (light, sepia, dark, Monokai), adjustable text size, and a progress bar with a marker per chapter.

🔒

Private by design

Books live only in the open tab. The helper only turns text into audio. No account, no tracking, no analytics.

Get EPUB Reader

  1. Install the extension: Firefox users install it straight from addons.mozilla.org. Chrome / Edge / Brave / Arc: load it unpacked from the releases page (chrome://extensions → Developer mode → Load unpacked) — store links for other browsers coming soon.
  2. Download the speech helper (Windows or Linux) from the same page and run it once — a terminal walks you through the install, then you never run it again.
  3. Click the toolbar button, choose an .epub, and start reading.
Reading works without the helper. Only read-aloud needs it — and if it isn't installed, EPUB Reader says so plainly, with a download link, wherever you expected to hear something. First listen needs internet; after that audio is cached on your computer.
